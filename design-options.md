# Design Options

Дата: 2026-05-18

Цель: временно сравнить четыре визуальных направления без финального внедрения одного варианта.

## Как смотреть

- Live preview: добавь к любому маршруту `?theme=a`, `?theme=b`, `?theme=c` или `?theme=d`.
- Скриншоты лежат в `design-previews/`.
- Основной пример dashboard:
  - `design-previews/variant-a-dashboard.png`
  - `design-previews/variant-b-dashboard.png`
  - `design-previews/variant-c-dashboard.png`
  - `design-previews/variant-d-dashboard.png`

## Варианты

| Вариант | Характер | Сильнее всего подходит | Возможный риск |
|---|---|---|---|
| A — Premium Real Estate Light | Теплая светлая палитра, мягкие тени, брокерская премиальность | Каталог, карточки объектов, object detail, кабинет | Может быть менее "операционным" для плотной админки |
| B — Clean SaaS Dashboard | Чистые серые/белые поверхности, синий акцент, строгие таблицы | Admin users, import, objects, рабочие сценарии | Менее эмоциональный и менее недвижимость-premium |
| C — Dark Premium | Графитовая темная тема, золотистый акцент, спокойный контраст | Демонстрация премиального dark mode, карта, каталог | Требует отдельной тщательной проверки всех состояний и контраста |
| D — Minimal Luxury | Почти белый минимализм, тонкие бордеры, меньше визуального шума | Дорогой спокойный интерфейс без сильного декоративного веса | Может выглядеть слишком сдержанно для action-heavy admin |

## Набор скриншотов

Для каждого варианта сохранены:

- `login`
- `dashboard`
- `catalog-grid`
- `catalog-list`
- `catalog-map`
- `object-detail`
- `admin-dashboard`
- `admin-users`
- `admin-objects`
- `admin-import`

Итого: 40 PNG-файлов.

## Спорные места

- Dark-вариант C лучше не внедрять как простую замену светлой темы без отдельного прохода по contrast/focus/error states.
- Вариант A сильнее всего меняет характер продукта в сторону премиального брокерского интерфейса.
- Вариант B самый рабочий для таблиц, но менее "дорогой" на каталоге.
- Вариант D самый тихий: хорошо снижает шум, но может потребовать чуть более выразительных active states.
