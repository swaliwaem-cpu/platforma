# Быстрое Редактирование Объектов В Админке

## Summary

Сделать в `/admin/objects` компактную Excel-подобную таблицу для быстрого редактирования объекта без входа в полную карточку. Все 14 колонок из макета должны помещаться без горизонтального скролла на desktop `1440px+`; на узких экранах горизонтальный скролл допустим.

Клик по ячейке открывает редактор. Сохранение: `Enter` или потеря фокуса, отмена: `Escape`. Название объекта открывает полную карточку, а редактирование названия включается маленькой иконкой внутри этой же ячейки.

## API / Interfaces

- Добавить `PATCH /objects/:id/status` в `apps/api/src/objects`:
  - body: `{ status: 'PUBLISHED' | 'ARCHIVED' }`
  - permission: `objects:publish`
  - `PUBLISHED` проходит существующие проверки публикации
  - `ARCHIVED` не требует заполнения publish-required полей
  - `DRAFT` не является целевым статусом в быстрой таблице
- Существующий `POST /objects/:id/publish` оставить рабочим.
- Новые frontend-типы держать локально в admin-модуле, без новых зависимостей и без Prisma-миграций.

## Assumptions

- Новые библиотеки не добавляем.
- Mobile/узкие экраны могут иметь горизонтальный скролл; запрет скролла относится к desktop `1440px+`.
- `DRAFT` может отображаться как текущий статус старых объектов, но быстрый выбор предлагает только `PUBLISHED` и `ARCHIVED`.
- В планировании файлы не изменялись; спорное место уже решено: название открывает объект, редактирование названия через иконку.
