# Исправление импорта Location и дублей застройщиков

## Правило выполнения

- Каждый пункт выполнения отмечается чекбоксом.
- Невыполненный пункт: `[ ]`.
- Выполненный пункт: `[x]`.
- По мере выполнения нужно обновлять этот файл и менять `[ ]` на `[x]`.
- Перед запуском repair-скрипта в режиме `run` сначала обязательно выполнить `preview` и проверить отчёт.

## Контекст

- Поле `Район` на детальной странице берёт значение из `RealEstateObject.primaryLocation`.
- Сейчас подтверждён баг импорта: у части объектов `primaryLocation` выбран из `rajon-okolo`, хотя настоящий район должен приходить из `rajony`.
- Пример: у `Дом «Палашёвский 11»` сейчас primary = `На Патриарших`, но корректный район из `rajony` = `Тверской`.
- `rajon-okolo` не удаляем: эти термины нужны как отдельное поле `Окружение`.
- Дубли застройщиков склеиваем только через ручной alias-конфиг, без автоматического выбора канонического имени.

## Assumptions

- Канонические имена застройщиков выбираются вручную через alias-конфиг.
- Новые библиотеки не добавляем.
- `rajon-okolo` остаётся полезной классификацией, но больше не используется как основной район.
