# Manual QA checklist

Этот чеклист нужен для проверки на живом окружении после запуска API, web, PostgreSQL, Redis и MinIO.

## Подготовка

- [ ] Выполнены миграции Prisma.
- [ ] Выполнен seed ролей, permissions и admin-пользователя.
- [ ] API доступен по `VITE_API_URL`.
- [ ] MinIO доступен API-сервису.
- [ ] Карта проверяется без `VITE_YANDEX_MAPS_API_KEY`; при наличии ключа отдельно проверяется JS API режим.

## Роли и доступы

- [ ] `admin` входит в систему и видит `/admin/objects`, `/admin/users`, `/admin/import`, `/catalog`, `/catalog/map`, `/cabinet`.
- [ ] `editor` может управлять объектами, но не может открывать управление пользователями.
- [ ] `editor` не может запускать WordPress import preview/run.
- [ ] Обычный `user` видит доступные разделы кабинета и не имеет доступа к admin endpoints.
- [ ] Backend возвращает отказ на закрытые endpoints даже при ручном запросе напрямую.

## Объекты и каталог

- [ ] Создание объекта из админки работает.
- [ ] Валидация формы объекта показывает ошибки для обязательных полей.
- [ ] Публикация объекта работает только при заполненных обязательных данных.
- [ ] Каталог открывается с опубликованными объектами.
- [ ] Фильтры каталога сохраняются в URL query params.
- [ ] Фильтры по поиску, застройщику, локации, метро, сроку сдачи, цене, статусу, презентации и координатам работают.
- [ ] Empty state каталога отображается при отсутствии результатов.
- [ ] Error state каталога отображается при ошибке API.

## Детальная страница

- [ ] Страница `/objects/:slug` открывается из каталога.
- [ ] Галерея, презентация, файлы, метро и локация отображаются корректно.
- [ ] Отсутствующие данные показывают fallback-текст.
- [ ] Объект без координат не ломает страницу и показывает fallback карты.

## Карта

- [ ] `/catalog/map` открывается и загружает markers объектов.
- [ ] Объекты без координат не попадают на карту и не ломают загрузку.
- [ ] Marker popup/card открывается по клику без API key.
- [ ] Переход с marker на страницу объекта работает.
- [ ] Кластеризация включается на большом количестве объектов в no-key и JS API режимах.

## Файлы

- [ ] Загрузка обложки работает.
- [ ] Загрузка галереи работает.
- [ ] Drag-and-drop сортировка галереи сохраняется.
- [ ] Загрузка презентации, планировок и документов работает.
- [ ] Ограничения MIME type и размера файлов срабатывают.
- [ ] Удаление файлов не оставляет сломанные ссылки в объекте.

## WordPress import

- [ ] Preview формирует отчет без записи объектов.
- [ ] Run импортирует объекты и файлы.
- [ ] Повторный run не создает дубли по `wpPostId`, `slug`, `wpAttachmentId`.
- [ ] Import reports доступны в `/admin/import`.
- [ ] Warnings/errors читаемы и помогают найти битые данные.

## Адаптивность

- [ ] `/login` корректно выглядит на мобильном и desktop.
- [ ] `/catalog` корректно выглядит на мобильном и desktop.
- [ ] `/catalog/map` корректно выглядит на мобильном и desktop.
- [ ] `/objects/:slug` корректно выглядит на мобильном и desktop.
- [ ] `/admin/objects`, `/admin/users`, `/admin/import`, `/cabinet` корректно выглядят на мобильном и desktop.
