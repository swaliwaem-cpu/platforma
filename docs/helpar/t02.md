# T02: Поиск, сравнение и grounded-ответы по данным Platforma

**What to build:** превратить чат в умный поисковик по текущим `RealEstateObject` и `FeedUnit`: пользователь формулирует условия обычным русским текстом, получает лучшие точные предложения, осмысленные альтернативы и проверяемый ответ без выдуманных цен или ссылок.

**Blocked by:** T01 — Авторизованный ИИ-помощник и оболочка разговора.

**Status:** ready-for-agent

- [ ] Query Planner преобразует пользовательский текст в валидируемый structured intent с task type, hard filters, soft preferences, required facts и признаком необходимости clarification.
- [ ] Поиск поддерживает доступные условия Platforma: бюджет, комнатность, район, метро, застройщика, срок сдачи и связанные object/lot filters.
- [ ] Цена и наличие Platforma читаются из текущей базы для каждого нового search run и не берутся из долгоживущего answer cache или памяти модели.
- [ ] Если критичных условий не хватает, помощник задаёт один короткий составной вопрос и не переспрашивает уже указанные параметры.
- [ ] Hard filters применяются до ranking; модель не может обойти их свободным текстом.
- [ ] Ответ содержит максимум три основных результата, причём точные совпадения всегда расположены раньше альтернатив.
- [ ] При отсутствии точных совпадений допускается максимум две альтернативы: близкий район, другой застройщик, другая комнатность или бюджет примерно в пределах плюс-минус 5–7 млн рублей.
- [ ] Каждое отклонение альтернативы явно названо; она не маскируется под точное совпадение.
- [ ] Ответ использует предсказуемую структуру «Лучшие по этим критериям» и отдельный блок альтернатив без свалки из ссылок.
- [ ] Карточки результата ведут на существующие страницы Platforma и показывают доступные project/lot PDF; генерация нового PDF не запускается.
- [ ] Цена и наличие содержат понятную freshness label, включая допустимую маркировку устаревших значений вроде «обновлено 10 часов назад».
- [ ] Обычные запросы маршрутизируются в Luna reasoning medium, сложные сравнения и скрытые условия — в Luna reasoning high.
- [ ] После schema, hard-filter, evidence, link и freshness validation допускается не более одного fallback на Terra reasoning medium; Luna max нигде не используется.
- [ ] Координаты, цены, наличие, freshness и ссылки считаются фактом только после детерминированной проверки найденных данных.
- [ ] При недостаточном evidence помощник честно отказывает или уточняет, а не дополняет ответ знаниями модели.
- [ ] Налоговые и юридические вопросы получают безопасное тематическое ограничение; помощник не выдаёт правовую консультацию.
- [ ] Обычный пользователь не видит внутренние evidence-ссылки, provider details или технические citations.
- [ ] Model и ranking tests используют fake Luna/Terra и проверяют exact-first, предел 3+2, допустимые relaxations, один fallback, usage telemetry и refusal без evidence.
