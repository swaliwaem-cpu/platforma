# T07: Сквозная приёмка, eval и пилотный rollout

**What to build:** доказать готовность всего помощника одним воспроизводимым authenticated journey и версионированным набором из 200 запросов, после чего подготовить безопасные этапы включения «администраторы → пилотные пользователи → все авторизованные» без автоматического production deployment.

**Blocked by:** T06 — Feedback, evidence audit и эксплуатационные ограничения.

**Status:** ready-for-agent

- [ ] Главный browser E2E работает поверх реального Nest application и disposable PostgreSQL/PostGIS с применёнными migrations.
- [ ] E2E использует fake Luna/Terra, fake Geo Provider, stub source connectors и local deterministic map style/tile fixtures и не обращается к платным или production services.
- [ ] Сквозной пользовательский flow покрывает auth, launcher, progress, clarification, exact search, alternatives, source-backed answer, external lot, stale price, PDF links, retry, history и feedback.
- [ ] Geo flow покрывает именованное место, ambiguity, manual point, radius hard filter, distances, primary/alternative markers, moved anchor и provider degradation.
- [ ] Map flow покрывает catalog filters, marker/list synchronization, selected state, fullscreen, object detail, attribution, mobile interactions и отсутствие Yandex requests.
- [ ] Admin flow покрывает отдельные permissions, source health, targeted refresh, geo aliases, review queue и полный evidence audit без утечки evidence обычному пользователю.
- [ ] Security checks покрывают 401, 403, чтение только собственных conversations, UUID probing, отсутствие frontend provider keys и безопасную serialization.
- [ ] Migration replay проходит на чистой PostGIS database и на upgrade scenario с существующими coordinates; presentation coordinate behavior остаётся неизменным.
- [ ] Versioned eval содержит 200 запросов по factual answers, structured search, comparisons, mortgage/installment, no-data, source conflicts, stale prices, external lots, geosearch, clarification и alternatives.
- [ ] Eval имеет нулевую терпимость к auth violations, hard-filter violations, source-priority violations, invented price/availability, unsupported links и evidence leakage.
- [ ] Остальные quality, latency и cost thresholds фиксируются в версии eval до запуска пилота и не меняются задним числом.
- [ ] Rollout управляется независимыми server-side feature flags для assistant, MapLibre renderer, Geo Provider и external connectors.
- [ ] Pilot allowlist поддерживает этапы: сначала администраторы, затем примерно десять существующих обычных пользователей, затем все авторизованные пользователи с правом чтения объектов.
- [ ] Переход на каждый следующий этап блокируется результатами eval, source health, configured budgets и отсутствием критических ошибок предыдущего этапа.
- [ ] Выполняются targeted assistant/map/geo tests, API tests, web tests, полный build, полный test suite и browser E2E; ни один gate не подменяется regex-only проверкой при наличии runtime test.
- [ ] Manual QA подтверждает русские labels и картографию Москвы, Павелецкая Плаза в радиусе 2 км, сложную рассрочку, tile/geocoder outages и desktop/mobile UX.
- [ ] Реальные OpenAI, LocationIQ или OpenFreeMap smoke описаны как отдельные bounded manual checks и не запускаются автоматически.
- [ ] Ticket не покупает provider plan, не создаёт production credentials, не применяет production migrations и не включает feature в production без отдельной команды пользователя.
