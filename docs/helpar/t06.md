# T06: Feedback, evidence audit и эксплуатационные ограничения

**What to build:** дать пользователю простой способ оценить ответ, а уполномоченному администратору — расследовать плохой результат по полному evidence trail, состоянию источников и provider telemetry без автоматического самообучения и утечки внутренней диагностики.

**Blocked by:** T03 — Официальные источники, ingestion и гибридная база знаний; T05 — Геопоиск по ручной точке и названию места.

**Status:** ready-for-agent

- [ ] Пользователь может поставить like/dislike, выбрать необязательную причину и оставить короткий комментарий.
- [ ] Один feedback создаёт review item, но не меняет model weights, prompt, ranking, routing или source priority автоматически.
- [ ] Человеческий reviewer видит feedback вместе с evidence и может классифицировать реальную ошибку отдельно от ошибочной пользовательской оценки.
- [ ] Чтение assistant audit защищено отдельным additive permission и недоступно обычному пользователю.
- [ ] Audit сохраняет исходный запрос, финальный ответ, structured intent, applied filters, candidate set, ranking decisions и использованные evidence revisions.
- [ ] Audit показывает модель, reasoning level, fallback, attempts, tokens, latency, error classification и freshness использованных данных.
- [ ] Evidence составляется из уже выбранных facts/chunks и revisions без отдельной генерации citations моделью.
- [ ] Администратор может фильтровать hard-filter violations, unsupported facts, stale prices без label, broken links, model fallbacks, provider errors, latency breaches и negative feedback.
- [ ] Source operations показывают health и последнюю успешную индексацию и позволяют адресно refresh-нуть разрешённый источник или ЖК.
- [ ] Geo operations показывают provider, status, latency, cache hit и число calls и позволяют подтверждать или исправлять internal aliases.
- [ ] Provider и model budgets имеют server-side поминутные и суточные ограничения и безопасные operational metrics.
- [ ] Secrets, raw credentials и чувствительные provider payloads не попадают в обычные logs, user contracts или audit UI.
- [ ] Conversation history и полный assistant audit удаляются по retention 30 дней; anonymized aggregate metrics хранятся до 180 дней; Source Revisions автоматически не удаляются.
- [ ] Пользовательский ответ скрывает evidence citations и внутреннюю диагностику, кроме рабочих Platforma/PDF links, обязательного external lot link и map attribution.
- [ ] Retention, permission и feedback tests проверяют 401/403/IDOR, cleanup boundaries и отсутствие автоматического влияния feedback на последующие ответы.
- [ ] Admin browser flow позволяет найти плохой ответ, открыть evidence trail и подтвердить source/model/geo telemetry без дополнительных платных вызовов.
