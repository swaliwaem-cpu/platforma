# T04: Полная миграция карт с Yandex Maps на MapLibre

**What to build:** заменить существующую картографию Platforma на единый provider-neutral Map Module с MapLibre и OpenFreeMap, сохранив поведение каталога и карточки ЖК, после чего полностью удалить Yandex Maps из production runtime.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Вводится provider-neutral Map Interface для points, selected point, bounds, viewport, open/select actions, loading, error, fullscreen и optional overlays.
- [ ] Map Module обслуживает карту каталога, карту карточки ЖК и готов для point picker без consumer-specific business logic внутри renderer.
- [ ] MapLibre GL JS является единственной интерактивной картографической библиотекой web Platforma.
- [ ] OpenFreeMap используется как default Tile Provider; style URL и provider enable state задаются runtime configuration.
- [ ] OpenFreeMap/OpenStreetMap attribution отображается стандартным контролом и не скрывается стилями.
- [ ] Карта каталога сохраняет текущие filters, point conversion, marker labels, marker selection, list synchronization, bounds-driven visible list, selected state, fullscreen и open-object action.
- [ ] Карта карточки ЖК отображается только при валидной паре latitude/longitude и сохраняет текущую предметную информацию и действия.
- [ ] Desktop и mobile сохраняют пригодные pan, zoom, fullscreen и touch interactions; keyboard focus и reduced-motion требования не деградируют.
- [ ] Tile Provider failure показывает понятный map fallback, но не ломает textual list, object data и рабочие ссылки.
- [ ] Latitude и longitude остаются canonical coordinate fields и продолжают обслуживать admin editing, map contracts и presentation generation.
- [ ] После parity-проверки удаляются Yandex script loader, frontend key/env contract, browser globals, Yandex-specific types, runtime copy и стили.
- [ ] Ни одна production page не запрашивает Yandex Maps domains и не читает Yandex frontend key.
- [ ] Feed format `YANDEX_REALTY` и его предметные feed identifiers не удаляются только из-за совпадения названия: scope ограничен интерактивным Yandex Maps runtime.
- [ ] Existing project/lot presentation snapshots и previews с координатами и без них остаются рабочими.
- [ ] Catalog и object-detail tests проверяют внешнее поведение через provider-neutral contract, а не MapLibre internals или порядок React effects.
- [ ] Browser tests используют deterministic local map style/tile fixtures, проверяют loading, attribution, selection, bounds, fullscreen, mobile и отсутствие Yandex network requests.
