# FIX-TOKEN: Контролируемые расходы ИИ-помощника

**What to build:** перевести discovery и пользовательский помощник на безопасную Luna-first схему, исключить случайные платные вызовы и ограничить расходы без ослабления локальной проверки фактов и источников.

**Status:** ready-for-agent

## Безопасный запуск

- [ ] Все тесты и обычная локальная разработка используют fake/stub.
- [ ] Реальные вызовы разрешаются только сочетанием `--live` и `ASSISTANT_PAID_CALLS_CONFIRMED=true`; наличие `OPENAI_API_KEY` само по себе ничего не запускает.
- [ ] Обычный запуск является настоящим dry-run: выбирает проекты и показывает верхнюю оценку расходов, но не вызывает провайдера.
- [ ] Discovery по умолчанию обрабатывает один отсутствующий проект. Полный пакет требует явных `--limit` и `--max-cost-usd`; `--refresh` отдельно разрешает повтор уже обработанного источника.

## Маршрутизация и discovery

- [ ] Перед моделью проверяются source registry, сохранённый checkpoint, официальный каталог и известные URL; Web Search используется только для оставшихся неизвестных источников.
- [ ] Основная модель discovery — `gpt-5.6-luna` с reasoning medium, `search_context_size: low`, `max_tool_calls: 1` и прежним безопасным пределом output tokens.
- [ ] `gpt-5.6-terra` reasoning medium допускается один раз для конкретного источника только после успешного ответа Luna, который не прошёл локальную identity/evidence validation, либо при независимом доказательстве существования проекта.
- [ ] Timeout, network error, 429 и 5xx не переключают модель на Terra.
- [ ] Лимиты: до 3 provider/Web Search calls для одного проекта; до 35 calls и 2 Terra fallback для пакета из 20. Превышение завершает запуск с понятным отчётом.
- [ ] Успешные результаты и отклонения сохраняются в локальном ignored-checkpoint с версиями модели, промпта и validator policy; повторный запуск не платит заново.
- [ ] Пользовательский Query Planner сохраняет контракт Luna Medium/High → один Terra Medium fallback. Web Search в пользовательские запросы не добавляется.

## Бюджет и наблюдаемость

- [ ] Общий usage policy учитывает provider, model, input/cached/cache-write/output tokens, Web Search calls и estimated USD по версионированному cost catalog.
- [ ] В OpenAI-режиме дневной долларовый бюджет обязателен и резервируется атомарно до вызова; после ответа расход уточняется по фактической telemetry.
- [ ] В отчёт discovery входят run ID, Luna/Terra calls, fallback, Web Search calls, токены и estimated USD. Промпты, найденный контент, raw provider payload и ключи не логируются.
- [ ] Публичные HTTP API не меняются. Допускаются только CLI-флаги, fail-closed environment settings, additive usage telemetry и необходимая additive migration.

## Проверки и приёмка

- [ ] Fake-тест доказывает отсутствие HTTP-вызовов без обоих live-разрешений.
- [ ] Тесты покрывают Luna-first, допустимый Terra fallback, отсутствие fallback при transport error и остановку по call/cost budget.
- [ ] Contract-тест фиксирует `max_tool_calls: 1`; повторный discovery использует registry/checkpoint и делает ноль provider calls, а `--refresh` выполняет новый ограниченный запуск.
- [ ] Cost-калькулятор воспроизводит фактические `$9.8537938` из сохранённой usage-фикстуры и считает Luna-сценарий без реального API.
- [ ] Запускаются targeted T02/T03 tests, API tests и build. Все автоматические проверки остаются бесплатными.
- [ ] Отдельный платный canary на 10–20 источниках допускается только по новой команде пользователя с лимитом `$0.50`; критерии — ноль ложных источников, покрытие не хуже Terra baseline и не более 10% fallback.

## Границы

- [ ] Патч не меняет Training-модуль, геопоиск, production-конфигурацию и не запускает реальные OpenAI-вызовы.
- [ ] Реальные цены фиксируются в cost catalog на дату реализации; изменение тарифа требует обновления каталога и тестовой фикстуры.
