# ИИ-помощник v2 — этап 1: классы, факты о ЖК, логи

Дата: 2026-09-26. Статус: план, ждёт утверждения.

## Зачем

Сейчас помощник (v2, коммит `7f29486`) умеет только искать лоты.
Он не знает, что такое «элит» или «премиум», не видит описание,
отделку и класс ЖК и ничего не запоминает о своих ответах.

После этапа 1 помощник:

- понимает запросы вроде «элитка в ЦАО до 300 млн с отделкой,
  до 10 минут пешком от метро» и превращает их в точный фильтр;
- отвечает на вопросы о конкретном ЖК: класс, отделка, потолки,
  цена за метр, метро, описание;
- объясняет термины рынка (классы, отделка, ипотека, эскроу, ДДУ);
- показывает под ответом источники с датой;
- сохраняет диалоги (с маскировкой телефонов и почты), даёт 👍/👎
  и считает расход.

Этапы 2 (база знаний: PDF и Google-ссылки) и 3 (сборщик сайтов
и новостей) в этот план не входят.

## Что уже решено

| Вопрос | Решение |
|---|---|
| Пользователи | Только брокеры. На проде пока видят только админы (`ASSISTANT_ROLLOUT_STAGE=ADMINS`), это не меняем |
| Приоритет | Знания и понимание запроса → аналитика → тексты и действия |
| Точность | Цены, сроки и наличие — только из данных. Общие объяснения — своими словами |
| Конфликт данных | Цены и лоты — фид. Акции, ипотека, новости — сайт застройщика. Правила — методички |
| Классы | Комфорт-класс, Бизнес-класс, Премиум-класс, Делюкс. «Элит», «элитка» и «de luxe» — синонимы Делюкса |
| Пустой класс (104 ЖК на проде) | Помощник предлагает, админ подтверждает |
| Критерии классов | Черновик пишет агент, пользователь правит |
| Модель | Остаётся `deepseek-v4.1-flash`. Сильную модель подключаем на этапе «аналитика» |
| Логи | Хранятся на сервере 90 дней, телефоны и почта маскируются, смотрят только админы, под ответом 👍/👎 |
| Расход | Только считаем, без лимита |
| Источники | Показываем под ответом с датой |
| Тестовый набор | Черновик пишет агент, пользователь правит; прогоняем на живой модели до и после |
| v1 | Удаляем все таблицы, enum и триггеры v1, **кроме двух таблиц метро**. Убираем права `assistant:audit:read` и `assistant:sources:manage` |
| pgvector | Оставляем, он нужен на этапе 2 |

## Факты, на которые опирается план

- На проде `property_class` заполнен у 236 опубликованных ЖК и пуст у 104.
  Значений всего четыре: «Бизнес-класс» (105), «Премиум-класс» (81),
  «Делюкс» (41), «Комфорт-класс» (9).
- В локальной базе класс почти пуст (2 из 314). Зато в
  `features_json.taxonomy` есть класс из WordPress:
  `biznes-klass`, `premium-klass`, `elitnyj`, `komfort-klass`.
- Время пешком до метро посчитано в v1 для всех ЖК на проде: таблицы
  `assistant_object_metro_route_facts` (одна строка на ЖК, ближайший вход)
  и `assistant_metro_access_points`. Скрипт пересчёта удалён вместе с v1,
  поэтому у новых ЖК этих данных не будет (см. «Риски»).
- Отделка лота лежит только в
  `feed_residential_unit_details.details_json.renovation/decoration`.
  Значения грязные: «без отделки», «whitebox», «WB», «0», «30»,
  «ТребуетРемонта». Отделка есть примерно у 5 тысяч из 14,7 тысячи лотов.
- Цена за метр у лота:
  `COALESCE(effective_price_per_meter, discount_price_per_meter, price_per_meter)`.
- Расчёт стоимости уже есть в модуле обучения:
  `estimateTrainingAiCost` в [training-ai-pricing.ts](../../apps/api/src/training/training-ai-pricing.ts).
  В нём есть цены `deepseek-v4.1-flash` и `deepseek-v4-pro`.
- Ни одна таблица v1 не используется текущим кодом. На таблицы v1
  ссылаются 8 полей в `User` и одно в `RealEstateObject`. Ещё в v1 есть
  5 триггерных функций, которые `DROP TABLE` не удаляет.

- **У новых ЖК нет минут до метро.** Скрипт пересчёта удалён вместе с v1.
  Для них фильтр `metroWalkMinutesMax` не сработает, а помощник должен
  говорить «нет данных». Пересчёт — отдельная задача: лимит OpenRouteService
  на проде 50 запросов в день, он общий с картой.
- **Отделка есть только у трети лотов.** Фильтр «с отделкой» отсечёт лоты
  без данных. Помощник должен явно писать, сколько лотов без информации
  об отделке.
- **Строгий список классов в админке.** Если кто-то вводит класс вручную
  нестандартно, после изменения получит ошибку. Все текущие значения на
  проде в список укладываются.
- **Эконом-класса нет в списке.** На проде нет ни одного такого ЖК. Если
  помощник предложит эконом при разметке, это решение пользователя.
- **Цифры в справочнике устаревают.** Медианы цены за метр по классам
  зашиты в текст с датой, их надо обновлять. Автообновление — кандидат
  в этап 2.
- **Размер промпта.** Справочник плюс описания ЖК увеличивают число токенов
  на вопрос. Следить по логам расхода. Если вырастет заметно, справочник
  уедет в базу знаний на этапе 2.
