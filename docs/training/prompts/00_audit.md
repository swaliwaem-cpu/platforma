# Prompt для Codex

Ты работаешь в репозитории `swaliwaem-cpu/platforma`, текущая рабочая ветка должна быть `on-ser`.

Выполни ТОЛЬКО этап 0: актуализация технического аудита и создание архитектурных документов. Production-код, Prisma schema и зависимости пока не изменяй.

Перед началом:
1. Выполни `git branch --show-current` и `git status --short`.
2. Не переключай ветку и не трогай чужие/untracked-файлы.
3. Прочитай:
   - `docs/training/spec/00_rules_business.md` — разделы про правила работы и технический контекст;
   - `docs/training/spec/04_stages_tests_acceptance.md` — только «Этап 0» и формат отчёта;
   - существующие инструкции репозитория, если есть `AGENTS.md`, README или CONTRIBUTING.

Проверь актуальность стека, auth/RBAC, Prisma, storage, workers, routing, tests и deploy. Не повторяй бессмысленный аудит всего репозитория; сравни реальный код с указанным контекстом и зафиксируй только drift.

Создай/обнови:
- `docs/training/00-repository-audit.md`;
- `docs/training/01-architecture-decision.md`;
- `docs/training/02-implementation-checklist.md`.

В checklist создай этапы 0–10 из файлов prompts и отметь только этап 0 после фактической проверки.

Запусти только безопасные команды чтения и существующие build/tests, если они не требуют изменения данных. Ничего не реализуй сверх аудита.

В конце дай отчёт:
1. подтверждённая архитектура;
2. найденный drift;
3. созданные файлы;
4. запущенные проверки;
5. риски;
6. готовность к этапу 1.

После отчёта ОСТАНОВИСЬ.
