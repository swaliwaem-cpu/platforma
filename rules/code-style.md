# Стиль работы

- Пиши чистый, понятный и поддерживаемый код.
- Не ломай существующую структуру монорепозитория.
- Держи изменения локальными для задачи и не трогай несвязанные файлы.
- Не откатывай чужие или пользовательские изменения без прямого запроса.
- Для ручных правок файлов используй точечные патчи, а не переписывание больших участков без необходимости.
